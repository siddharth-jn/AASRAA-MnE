# Administrator guide

Open `/admin` and sign in with an ADMIN account.

Create a programme first, then create its project and select its reporting centres. Centres store a public name, type, broad region, capacity when relevant, and provenance note. Avoid exact addresses or coordinates unless Aasraa authorizes their operational use.

Create an indicator from **Indicator Definitions**:

1. Select the project and enter a unique code, name, definition, category, and unit.
2. Choose the data type, reporting frequency, time aggregation, and centre aggregation.
3. Set validation minimums, maximums, precision, and the effective date.
4. Select reporting centres.
5. Configure evidence requirements, allowed extensions, size, and count limits.
6. Save and review it in Data Entry.

Set `active` off to archive a project, centre, or indicator. The admin interface intentionally omits destructive record actions for historically referenced configuration. Definition changes generate version snapshots so previously submitted records keep their original rules.

Create staff in **Users**, assign one role, then select the projects and centres they may access. Password fields are required when creating a user and ignored when left blank during editing.
