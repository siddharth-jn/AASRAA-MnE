# User guide

Sign in at `/login` with the account provided by an administrator. Use **Forgot password?** to request a reset link through the configured mail service. Use **Change password** in the sidebar to update a known password and close other signed-in sessions. The dashboard opens on September 2026 in demo mode and shows projects, centres, completion, approval status, key outcomes, and recent submissions.

Use **Projects** to inspect programme descriptions, leads, assigned centres, configured indicators, consolidated target performance, and KPI details. Use **Centres** to see assigned programmes and staff, completeness, and reporting records. Dashboard period controls support monthly, quarterly, half-yearly, annual, year-to-date, and custom ranges. A partial custom month is excluded with a visible warning because monthly records cannot be prorated safely.

To report data, open **Data Entry**, choose a month, and select an indicator-centre row. The form can display a number, percentage, ratio calculation, date, yes/no choice, text field, single choice, multiple choice, or status control according to the administrator's configuration. Configured ranges and accepted values are enforced on the server. The current target appears beside the reporting period when one applies. Attach evidence when required. **Save draft** keeps the record editable. **Submit for approval** places it in the manager queue; indicators configured without approval become official when submitted.

Senior Program Leads use **Approvals** to inspect the value, target, submitter, notes, evidence previews, and earlier revisions. Confirm evidence review when the indicator requires it. Approve valid records, or enter a comment and return or reject them. A submitter cannot approve their own revision. Submitters receive the decision as an in-app notification, and reviewers receive new-submission alerts.

Use **Reports** to select a period, project, centre, indicator, or category. Official reports include approved revisions only and show targets, achievements, variance, percentage, trend, approval state, and completeness. Download CSV or Excel, or use **Print report** for the print layout. Missing, zero, pending, and not applicable remain distinct states.

Program Leads and managers use **Imports** to migrate CSV or XLSX history. Select a project, upload a file, map its source columns, validate the rows, and review valid, invalid, duplicate, and evidence-required records. Confirmation creates editable drafts; it never silently overwrites or approves existing reporting data. Project-specific CSV and XLSX templates are available from the import page.

Use **Data Quality** to review evidence compliance, approval turnaround, on-time submissions, returned submissions, unapproved records, and completeness by centre. The notification icon shows unread workflow and deadline reminders.
