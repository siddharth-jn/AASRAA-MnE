# Features

## Implemented

- Laravel 13, MySQL 8, Blade, Tailwind CSS 4, Alpine.js, Livewire 4, and Filament 5 foundation
- Secure login, logout, password reset, password change, rate limiting, hashed passwords, session regeneration, other-session invalidation, and no public registration
- ADMIN, SENIOR PROGRAM LEAD, PROGRAM LEAD, CENTRE COORDINATOR, and VIEWER roles
- Project and centre scope enforcement on server-side queries
- Organization, project, centre, KPI detail, and data quality dashboards with scoped period filters
- Filament administration for users, programmes, projects, centres, and indicator definitions
- Guided indicator configuration for categories, typed inputs, accepted values, calculated ratios, validation ranges, date limits, reporting frequency, project and centre assignment, aggregation, evidence, approval, and archival state
- Monthly, fiscal quarterly, half-yearly, and annual target management with numeric, range, and status targets
- Definition version snapshots and audited target changes preserve the rules used by historical records
- Data-entry controls and server validation generated from indicator configuration
- Draft, submit, approve, return, reject, correct, and resubmit workflow with revision history, concurrency protection, and self approval prevention
- Private evidence upload, authorized image/PDF preview, file download, evidence review confirmation, and preserved historical proof
- In-app workflow notifications, optional email notifications, unread counts, and scheduled reporting deadline reminders
- Reporting completeness by project, centre, and reporting obligation, including missing indicator lists
- Approved-only monthly, quarterly, half-yearly, annual, YTD, and custom-period reports with target comparison, variance, performance, trend, CSV/XLSX export, and print layout
- Configured aggregation across time and centres, including combined numerator/denominator ratios and missing-value preservation
- CSV/XLSX upload, flexible column mapping, row validation, duplicate detection, manual-review flags, draft-only confirmation, downloadable templates, and import history
- Deterministic demo data for April through September 2026
